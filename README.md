🛡️ SQLi Scanner Tool

A simple yet powerful tool designed to detect SQL Injection (SQLi) vulnerabilities in web applications.

This tool helps penetration testers and web developers quickly identify potential database injection flaws during security assessments.

🚀 Features:
Automatic SQL Injection vulnerability scanning
Supports testing multiple URLs at once
Clear and readable results output
Lightweight and fast execution
Suitable for security testing and learning purposes
⚙️ How to Use:
Run the tool
Enter the target URL or a list of URLs
Start the scan
Review the results for possible vulnerabilities
